Colle ici manuellement (si le bouton ci-dessus n'a pas fonctionné)
  1. Écris ta demande ci-dessus, puis clique sur Générer le prompt pour vérifier ce qui sera envoyé (il inclut automatiquement le fichier menu actuel).
  2. Clique sur Envoyer à ChatGPT (ou Ouvrir dans l'app Claude si tu l'as installée) : le prompt est copié dans le presse-papier au cas où, et l'IA s'ouvre dans un nouvel onglet. Connecte-toi si besoin, colle le prompt s'il n'est pas déjà rempli, puis envoie le message.
  3. Si tout est clair, l'IA te renvoie le fichier complet régénéré : copie-le entièrement (le bloc de code en entier, avec Ctrl+C).
  4. Reviens ici et clique directement sur 📥 Coller le nouveau menu → voir le diff : tu atterris tout de suite sur l'onglet Diff pour vérifier les changements avant de les appliquer.
  5. Si ça te convient, va dans l'onglet Brut pour confirmer, ou directement sur Push pour publier.
ℹ️ Le bouton "app Claude" ne fonctionne que si l'application de bureau Claude est installée sur cet ordinateur. Le bouton "Coller le nouveau menu" utilise le presse-papier automatiquement ; si le navigateur refuse la permission, une zone de collage manuel apparaît en secours.
